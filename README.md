# mini-git

A small Git-like version control system built from scratch in C.

## About

mini-git is a project built to understand Git's core concepts and the system behind version control.

The goal is not to fully recreate Git, but to learn how fundamental concepts such as file storage, hashing, staging, commits, and branches work by implementing them step by step in C.

## Technologies

* C
* GCC / Clang
* POSIX API
* Git / GitHub

## Goals

* Understand how Git works internally
* Practice file system operations in C
* Gain hands-on experience with hashing and data structures
* Improve systems programming skills
* Build a software project from scratch

## Development Approach

The project is being developed without using Git's source code or existing Git libraries.

Each feature is first studied to understand its underlying logic, then implemented from scratch in C and tested independently.
